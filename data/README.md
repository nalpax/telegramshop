# Приватный контент курса

В GitHub включён только `free-lessons.json`: первый урок, который владелец решил выдавать бесплатно после подписки. Полные тексты платного курса, PDF и платные промпты не опубликованы.

`server/api.mjs` при отсутствии приватных файлов использует бесплатный урок. Приложение и демонстрация дизайна работают. Оплата автоматически недоступна, пока не добавлены все 24 урока и тексты ресурсов: покупатель не должен заплатить за отсутствующие материалы.

## Быстрый способ (рекомендуется): импорт из пакета

Из корня проекта: `node scripts/import-package.mjs <путь к Vibentry_MiniApp_Handoff>`. Скрипт создаёт `data/lessons.json`, `resources.json`, `prompts.json`, `articles.json`, обновляет `free-lessons.json` и копирует скриншоты уроков в `public/assets/lessons/`. Структура уроков: `{id, title, outcome, markdown, task, confirmation}`. Всё, кроме `free-lessons.json`, игнорируется Git.

## Старый способ: импорт из PDF v0.2 (устарел, тексты на «ты»)

1. Получи **лично от владельца** файл `Vibentry_Course_v02.pdf` из его архива `Vibentry_Archive_extra.zip`. Не скачивай чужую копию и не ищи его в публичном репозитории.
2. Создай каталог `handoff/course/` и помести туда PDF. Эта папка игнорируется Git; не добавляй её с `git add -f`.
3. Если PyMuPDF не установлен, установи его в подходящее Python-окружение. Python нужен только для переноса материала, не для работы бота.
4. Из корня проекта выполни `python scripts/import-course.py`. Импортёр восстановит 24 урока и извлечёт три исходных текстовых блока из PDF v0.2 в `data/lessons.json` и `data/resources.json`.
5. Сверь полученные тексты с оригиналом и перезапусти сервер. На сервер развёртывания передавай эти файлы безопасным способом, отдельно от публичного GitHub.

Можно вместо PDF передать разработчику уже подготовленные JSON из частной локальной сборки владельца. Они тоже должны оставаться вне Git.

Пример структуры урока (не содержимое платного курса):

```json
{
  "id": 2,
  "outcome": "Результат урока",
  "sections": [{"title": "Название раздела", "paragraphs": ["Текст автора"]}],
  "task": "Практическое задание автора",
  "confirmation": "Я выполнил практическое задание"
}
```

`lessons.json` — массив с ID 1–24. `resources.json` — объект со строковыми полями `notes`, `first-prompt`, `mobile-prompt`. Настоящие тексты должны поступить из материалов владельца, не из примера выше.
