## Что сделано

**Учебный проект и объёмный сайт**
- Четыре этапа: Структура, Дизайн, Контент, Публикация.
- Этап завершается, только когда пройдены его уроки и засчитаны его задания. Считает сервер (`GET /api/project`).
- Если открыть этап для просмотра, он не засчитывается. Выбранный этап только подсвечивает свой слой иллюстрации.
- Сайт сделан на HTML и CSS с перспективой: браузерная панель, первый экран, карточки, низ страницы, палитра, отметка запуска. Пять состояний по числу реально завершённых этапов (0–4).
- При смене этапа слои плавно сдвигаются. Бесконечной анимации нет, `prefers-reduced-motion` отключает движение. Без анимации картинка тоже понятна.
- Это не 3D-модель (.glb) и не готовая картинка из макета.

**Задания уроков** (`server/exercises.mjs`, таблица привязки — `handoff/LEARNING_MAP_RU.md`)
- Восемь заданий к настоящим урокам 03, 07, 08, 09, 12 и 22. Четыре типа:
  - A — улучшить промпт;
  - B — собрать структуру кнопками ↑ ↓ ×, с клавиатуры;
  - C — найти ошибку или разобрать ситуации;
  - D — чек-лист перед запуском.
- Правильные ответы, подсказки и правила проверки есть только на сервере. Разбор приходит после ответа.
- Проверка идёт по признакам из урока. Приложение прямо пишет, что это не оценка ИИ. Для чек-листа пишет, что сайт не проверялся автоматически.
- Состояния: начальное, ввод, проверка, понятная ошибка, разбор «что хорошо и что дописать», новая попытка. Результат сохраняется в аккаунте.
- Неудачная повторная попытка не отнимает засчитанный результат.
- Черновик ответа хранится на устройстве до проверки, поэтому случайный уход со страницы его не теряет.
- Доступ — как у урока: 01–05 после подписки, остальное после покупки.
- Без доступа видно только название и навык, содержание задания не отправляется.
- Бесплатные запуски «Практикума» эти задания не тратят.

**Экраны**
- **Меню на ПК** (212 px): Главная, Уроки, Мой проект, Материалы, Практика, Профиль. Админка показывается только админам.
- **Меню на телефоне:** Главная, Уроки, Материалы, Практика, Профиль. Проект открывается с карточки на главной.
- **Главная.**
  - ПК: проект с объёмным сайтом, справа ближайшее доступное задание, под проектом текущий урок с кнопкой «Продолжить урок», внизу ряд материалов.
  - Телефон: шапка, проект, текущий урок, быстрый доступ, задание.
  - Прогресс и урок берутся из настоящих данных. Для нового пользователя показывается начальное состояние.
- **Уроки.**
  - ПК: слева поиск, модули, уроки и их состояния; справа выбранный урок — чему научитесь, задание к уроку, этап проекта, «Открыть или продолжить».
  - Телефон: список, по нажатию открывается урок.
- **Читалка урока:**
  - добавлены «Содержание урока» и блок «Практика урока» с заданиями этого урока;
  - чек-листы, термины, закладки и место чтения сохранены;
  - длина строки ограничена.
- **Материалы.**
  - Фильтры: Шаблоны, Промпты, База, Термины, Избранное. Поиск, звёздочка на каждой карточке.
  - ПК: справа постоянный предпросмотр — назначение, состав и небольшой фрагмент, только если материал вам открыт.
  - Телефон: предпросмотр в нижней панели, она закрывается кнопкой, жестом «Назад» Telegram или клавишей Esc.
  - Закрытый материал в предпросмотре не раскрывается.
  - Шаблоны добавлены в существующее серверное избранное (`kind = resource`).
- **Практика.**
  - ПК: слева задания уроков и тренажёры, справа рабочая область.
  - Телефон: список, затем отдельный экран задания.
  - Ограничение тренажёров для Free (3 запуска) не менялось.
- **Мой проект:** объёмный сайт, этапы и панель этапа — объяснение, задание, уроки, критерии, переход к уроку или заданию.

## Новые файлы и миграции

| Файл | Что это |
|---|---|
| `server/exercises.mjs` | Задания, проверка ответов, этапы проекта (только сервер) |
| `public/js/learn.js` | Объёмный сайт, молочные предметы, этапы, отрисовка заданий |
| `public/learn.css` | Слой стилей: палитра, фон, сетка двух колонок, компоненты |
| `public/assets/bg-outlines.svg` | Контуры страниц для фона |
| `tests/exercises.test.mjs` | Тесты заданий, доступа, сохранения, этапов |
| `handoff/LEARNING_MAP_RU.md` | Урок → навык → тип → критерий → этап |

- **Миграция базы:** новая таблица `exercise_results(user_id, exercise_id, version, answer, result, passed, attempts, updated_at)`. Создаётся сама при запуске (`CREATE TABLE IF NOT EXISTS`) и входит в резервную копию.
- Других изменений схемы нет.
- **API:**
  - новые: `GET /api/project`, `GET /api/exercises`, `GET` и `POST /api/exercises/:id`;
  - `GET /api/articles` теперь отдаёт заголовки разделов (`outline`) для предпросмотра, без текста;
  - избранное принимает `kind = resource`.
- В `public/js/course.js` добавлено поле `outcome` для каждого урока: одна строка «Результат урока» для описания программы, не текст урока.

- `npm test`: 81 из 81.
- `browser-smoke.py`: PASS. Сценарии:

  - бесплатный и платный пользователь;
  - открытие доступного урока и отказ в закрытом;

  - фрагмент промпта у Pro;

## Ограничения и что осталось

- **Макеты:** см. «Откуда взят дизайн».
- **Живой Telegram:** экран в живом Telegram (iOS, Android, Desktop) не проверялся. Safe area и «Назад» проверены только на заглушке Telegram в Playwright.
- **Проверка заданий:** по правилам, без ИИ. Необычный, но верный ответ на задание A может не набрать все признаки. Разбор подскажет, что дописать.
- **Мобильное меню:** в нём нет пункта «Мой проект», проект открывается с главной. Если нужен отдельный пункт, меню станет плотнее (6 пунктов).
- **Главная:** блоки v1.1 «Путь курса», «Промпт дня», категории промптов и плитки статистики с неё убраны. Промпты, их категории и «Недавно открытое» остаются в «Материалах» и на главной.
- **Скриншоты:** снимки всей страницы в Chromium искажают цвет 3D-слоёв, поэтому скриншоты сделаны окном высотой со страницу.
- **Выкладка:** не выполнялась. После проверки: резервная копия в админке, затем `npm run deploy:cloudflare`. Таблица создастся сама.
