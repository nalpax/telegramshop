# Запуск Vibentry: от нуля до первых платежей

Идите по порядку. Каждый пункт заканчивается проверкой.

## 1. Бот и канал
1. В BotFather: `/newbot`. Токен — в `.env` как `BOT_TOKEN`, имя без @ — в `BOT_USERNAME`. Токен никому не показывайте.
2. Создайте канал (и чат, если нужен). Добавьте бота **администратором**. Без этого проверка подписки не работает.
3. Узнайте свой Telegram ID командой `/id` у запущенного бота и впишите в `ADMIN_IDS`.

## 2. Сервер
1. Нужен публичный адрес с HTTPS (например, VPS + Caddy/Nginx). Впишите его в `APP_URL`. `NODE_ENV=production`.
2. `cp .env.example .env`, заполните. Положите приватный контент в `data/` (из закрытого архива).
3. Два процесса: `npm start` и `npm run bot` (systemd или pm2). Один `DATABASE_PATH`.
4. Резервная копия: ежедневно копируйте `var/vibentry.sqlite` (вместе с `-wal`, лучше командой `sqlite3 .backup`).
5. Проверка: `/health` отвечает `{"ok":true}`, бот отвечает на `/start`.

## 3. Mini App в BotFather
`/mybots` → бот → Bot Settings → Menu Button и Main Mini App → адрес `APP_URL`. Откройте бота с телефона и с компьютера.

## 4. Каналы доступа
Откройте в приложении **Админка → Доступ**, добавьте канал/чат, нажмите «Проверить бота» (должно быть «Бот — администратор»), сохраните. Затем зайдите вторым аккаунтом: до подписки урока нет, после — есть.

## 5. Цены
**Админка → Акции**: цена в Stars (обязательно), при желании в ₽ и USDT, скидка, промокоды. Telegram требует Stars для цифровых товаров внутри Telegram, поэтому Stars — основной способ.

## 6. Тестовая оплата Stars
Выставьте цену 1–5 Stars, оплатите вторым аккаунтом. Должно: прийти сообщение от бота, в профиле появиться красный **Pro**, открыться все уроки. Проверьте отмену оплаты и повторное нажатие. Верните нормальную цену.

## 7. Платёжные провайдеры (по желанию)
Для каждого: ключи в `.env` → перезапуск → переключатель в **Админка → Акции → Способы оплаты** → цена в нужной валюте.
- **Platega** (карта/СБП): `PLATEGA_MERCHANT_ID`, `PLATEGA_SECRET`. В кабинете укажите callback-адрес `APP_URL/api/webhooks/platega` (HTTPS с настоящим сертификатом). Первый платёж — на минимальную сумму.
- **CryptoBot**: приложение в @CryptoBot → Crypto Pay → My Apps → токен в `CRYPTOBOT_TOKEN`, Webhooks → `APP_URL/api/webhooks/cryptobot`. Сначала можно проверить в @CryptoTestnetBot (`CRYPTOBOT_API_BASE`).
- **xRocket**: `XROCKET_API_KEY` и `XROCKET_WEBHOOK_SECRET`, webhook `APP_URL/api/webhooks/xrocket`. **Обязательно** проверьте на тестовой сети: часть полей API в открытой документации не читалась, и адаптер написан осторожно (см. комментарий в `server/providers/xrocket.mjs`). Пока не проверили, держите выключенным.
Проверка любого провайдера: платёж → в течение минуты у покупателя Pro; повторная доставка webhook ничего не дублирует; неверная подпись возвращает 401.

## 8. Защита и утечки
- Приватный контент только в `data/` на сервере. Репозиторий — публичная часть без платных текстов.
- Если текст курса утёк: `npm run trace-leak < текст.txt` покажет Telegram ID, чей аккаунт читал этот фрагмент (невидимая метка). Откройте участника в Админке и отзовите доступ при необходимости.
- В Админке → Журнал видны записи «частые запросы»: так выглядит парсинг.
- Честно: скриншоты и фото экрана остановить нельзя. Защита строится на водяном знаке с именем и ID читателя, метке в тексте, лимитах и том, что контент выдаётся только оплатившим.
- Любые файлы, которые бот отправляет в сообщениях, отправляйте с `protect_content: true`.

## 9. Перед открытием для людей
`npm test` зелёный; `npm run check-links` без битых ссылок (закрытые для ботов проверьте вручную); пройдён весь путь: подписка → бесплатный урок → оплата → урок 2 → возврат в приложение на другом устройстве (прогресс на месте).
