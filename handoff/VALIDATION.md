# Проверка перед передачей · 28 октября 2026

## Дополнительно: версия для GitHub

Проверен чистый экспорт только файлов, включённых в Git, без `data/lessons.json`, `data/resources.json` и PDF. В нём успешно прошли `npm run check`, все 6 серверных тестов и браузерные сценарии на 320/390/1280 px. Тесты используют синтетические платные материалы. Неполный контент блокирует создание платёжных счетов. Повторный импорт личного PDF отдельно проверен в временной копии: 24 урока и 3 текстовых ресурса. Приватные результаты импорта в GitHub не отправляются.

Проверено в текущей среде, без настоящего токена бота и реальных списаний.

- `npm run check` — синтаксис JS/Node, наличие логотипа и иллюстрации, структура первого бесплатного урока.
- `npm test` — **6 пройденных тестов**: подпись Telegram, подмена/просрочка initData, платежи и повторная доставка, пожизненное право и возврат, параметры бота, скидка/окончание акции, API и доступ администратора. Интеграционный тест также проверяет отсутствие доступа у второго Telegram ID и запрет выдачи приватных исходников как статических файлов.
- `python scripts/browser-smoke.py` — Chromium, **320×740, 390×844, 1280×900**: стартовая подписка, явно обозначенное демо, главная, настоящий первый урок, задание, сохранение прогресса, закрытые уроки, поиск, каталог, профиль. Нет JS-ошибок и горизонтальной прокрутки на главной.
- Дополнительные UI-fixtures: авторизованный администратор редактирует 750 Stars / скидку 20%, окно покупки показывает 600 Stars и разовый доступ. Тестовая отмена окна оплаты не выдаёт доступ. Это синтетические ответы браузерного теста, не реальный платёж и не выбранная владельцем цена.
- Просмотрены мобильные скриншоты главной и стартового экрана; иллюстрация не перекрывает заголовок. Исправлены раздача файлов и зона нажатия чекбокса.

Не выполнено: деплой HTTPS, реальные getChatMember / createInvoiceLink / successful_payment, проверка в настоящем клиенте Telegram, боевой возврат, восстановление реального backup. Для этих шагов нужны настройки владельца. Они не заменены демо или тестовыми ответами.

В ZIP нет `.env`, SQLite с пользовательскими данными, Git-метаданных или токенов. `handoff/course` содержит авторские исходные PDF; хранить их непублично.
