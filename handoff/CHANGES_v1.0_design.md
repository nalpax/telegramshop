# v1.0 — редизайн (слой `public/design.css`)

Подключён после `style.css` в `index.html`. JS и разметка не менялись, откат — убрать одну строку `<link>`.

Принципы (по design-taste / anti-slop): плоские поверхности и линии 1px вместо градиентов, свечений и теней;
акцент лайм только на главном действии и прогрессе; оглавление уроков и список промптов — как в книге (строки с разделителями, без карточек);
чтение урока: 17px / 1.75, результат урока — цитата с линией слева; все тексты ≥ 11px, цели нажатия ≥ 44px;
токены `--bg --surface --line --ink --accent --gold`; Pro — золото, Free — нейтральный; светлая тема — только заменой токенов.

Проверено скриншотами 390 и 1280 (главная, уроки, промпты, чтение, профиль, оплата, админка). Не проверено в живом Telegram.
